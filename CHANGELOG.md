# Changelog

## 0.1.0 — Candidate software release, 6 October 2026

- Added configurable location-year raster extraction with separately labelled
  historical pixel-square and geodesic-circle strategies.
- Added explicit coordinate declarations, raster metadata, mask/zero policies,
  counts, run manifests and synthetic examples.
- Added stored-table auditing, provenance/rights notes and citation instructions.
- Recovered historical producer evidence and documented known measurement issues.

This software version does not announce a public release of the real company-year
dataset or a submission-ready manuscript.
